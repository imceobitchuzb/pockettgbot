# 🚀 AI Trading Terminal & Telegram Bot Signals (90%+ Accuracy)

Интеллектуальный аналитический торговый терминал и Telegram-бот, спроектированный специально для рынков **OTC** (Over-The-Counter) и **Биржевых валютных пар/криптовалют** (Pocket Option, Quotex и др.).

---

## 📸 Соответствие дизайну и скриншотам

- **Центральная сигнальная карточка**: В точности повторяет макет из Скриншота 3 (динамическая стрелка направления, бейдж «Ваш сигнал: BUY / SELL»).
- **«Процент залёта» (Точность 90%+)**: Расположен ровно на месте, помеченном красной цифрой «1», вычисляет математическую вероятность успеха на основе мульти-индикаторного конфлюэнса.
- **4 Информационные плитки**:
  - `Цена входа` (например, `0,66147`)
  - `Цена выхода` (динамический целевой уровень)
  - `Время экспирации` (переключатель 1 мин, 2 мин, 3 мин, 5 мин)
  - `Результат` (`WIN` / живой таймер обратного отсчета)
- **Аналитический «мозг» (Скриншот 1 и 2)**:
  - **ZigZag (5 12 3)**: поиск локальных экстремумов и истинного направления волны.
  - **Parabolic SAR**: выявление импульса ускорения тренда.
  - **Vortex Indicator (14)**: пересечение линий VI+ и VI-.
  - **RSI (14)**: фильтрация зон перекупленности и перепроданности.
  - **Aroon (15)**: сила восходящего и нисходящего тренда.
  - **Bollinger Bands & MACD**: подтверждение волатильности и гистограммы.
- **Анализ по фото / скриншоту («или же отправляя фото»)**:
  - Загрузка скриншота графика из Pocket Option прямо на сайте или отправка в Telegram-бот.
  - Компьютерное зрение автоматически сканирует свечной ряд, положение индикаторов и выдает сигнал с процентом залёта!
- **Живой свечной график**: Прямой эфир котировок с обновлением каждую секунду через WebSocket.

## ⚡ Быстрый запуск

### Вариант 1. Запуск в 1 клик на Windows
Просто дважды кликните по файлу:
```
start.bat
```

### Вариант 2. Запуск через терминал
```bash
# 1. Установка зависимостей (уже установлены в вашей системе)
python -m pip install -r requirements.txt

# 2. Запуск веб-терминала
python run.py
```
После запуска откройте в браузере: **`http://localhost:8000`**

## 🤖 Подключение Telegram Бота

Терминал полностью готов к интеграции в Telegram как **Telegram Web App** и как **Чат-бот**:

1. Откройте Telegram и напишите боту **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`, придумайте имя и юзернейм для вашего бота.
3. Скопируйте полученный токен (API Token).
4. Откройте файл `config.py` и вставьте ваш токен в строку:
   ```python
   BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
   ```
   *(Или укажите `WEBAPP_URL` на ваш домен/ngrok/локальный IP)*
5. Запустите:
   ```bash
   python run.py
   ```
6. В Telegram-боте будут доступны:
   - Кнопка запуска терминала: **🚀 Открыть Терминал Сигналов**
   - Команды: `/signal`, `/otc`, `/stats`
   - **Отправка скриншота**: отправьте боту фото графика Pocket Option, и он мгновенно пришлет подробный разбор с процентом залёта!
